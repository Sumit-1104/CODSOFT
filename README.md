## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Sumit-1104/CODSOFT.git
```

### 2. Navigate to the Project

```bash
cd CODSOFT
```

For example:



